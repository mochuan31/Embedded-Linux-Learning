# Day03（2026-07-28）
## ★ 工程习惯
1. 操作前、操作后执行 `pwd` + `ls`，确认当前位置和目录内容。
2. `rm` 前先确认删除对象，避免误删。
3. 操作时始终建立目录地图，清楚**我在哪、目标在哪**。
4. `rm`、`mv`、`cp`、`>` 等重要命令，回车前检查一遍命令和路径。
5. 不确定文件作用时，不删除；先查看、确认，再操作。
## ★ 今日知识
**文件查看**
```bash
cat 文件名      # 查看整个文件（小文件）
head 文件名     # 查看前10行
tail 文件名     # 查看后10行
```
**输出与重定向**
```bash
echo "Hello" > file.txt     # 覆盖写入
echo "Hello" >> file.txt    # 追加写入
```
> Linux 思想：**命令产生输出，重定向决定输出去哪里。**
## ★ 易错点
- `>`：覆盖原内容。
- `>>`：追加内容，不覆盖原文件。
- `echo` 一次输出一行，多个参数默认以空格连接。

## ★ 一句话总结
> **命令负责产生输出，重定向负责改变输出方向。**
