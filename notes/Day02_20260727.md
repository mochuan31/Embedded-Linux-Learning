## 开发板连接

查看串口：

```bash
ls /dev/ttyUSB*
```

输出：

```text
/dev/ttyUSB0
```

说明：Ubuntu 已识别 USB-TTL，并创建了对应设备文件。

连接开发板：

```bash
sudo picocom -b 115200 /dev/ttyUSB0
```

参数：

- `sudo`：管理员权限
- `picocom`：串口终端工具
- `-b`：指定波特率
- `115200`：通信速度
- `/dev/ttyUSB0`：串口设备文件

## 今日理解

- Linux 将硬件抽象成文件（**一切皆文件**）。
- `ls`、`cat` 等命令是 RootFS 中的程序，不属于 Linux Kernel。
- 程序控制硬件流程：

```text
程序 → Linux Kernel → Driver → 硬件
```

## 今日总结

 **Linux Kernel 管资源，Driver 控硬件。**
